Data Caveats

  • Per-query CTR join (Q1 × Q2) not fully computed — Mixpanel returns grouped rows, not user-level join. CTR table is approximate for top queries only.
  • keyword (search event) and query (click event) are different property names for the same user-typed string — join is text-match, not event-linked.
  • Cohort exclusivity (FnO > Intraday > Delivery) not enforced — Mixpanel doesn't support set-difference cohorts without saved cohorts or Redshift.
  • Keystroke events inflate head tier — "23", "in", "ni" are partial keystrokes, not final intents.
  • semantic_result interpretation is unverified — engineering must confirm whether true = semantic ran (all queries) or true = semantic fallback (zero-result only).
